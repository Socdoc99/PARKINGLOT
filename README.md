# PARKINGLOT

Primer andamiaje (scaffold) de una app móvil para gestión de parqueaderos, generado con Ionic + Angular.

## Qué hace

Por ahora, solo la estructura de rutas y páginas vacías: login, registro, landing, reservas y lectura de código QR. Todavía no tiene lógica implementada ni conexión a un backend.

## Stack

Angular 20, Ionic 8, Capacitor 8, TypeScript.

## Cómo ejecutarlo

```bash
npm install
npm start
```

## Estado del proyecto

Etapa inicial / andamiaje. Sin backend ni funcionalidad implementada todavía. El desarrollo de este trabajo final continuó en un enfoque distinto en [PARKING-LOT](https://github.com/Socdoc99/PARKING-LOT), que sí tiene backend funcional.
